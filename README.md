# Kubernetes & Platform Engineering Projects

Hands-on enterprise-level projects focused on Kubernetes, AWS, DevOps, Cloud Infrastructure and Platform Engineering.

| # | Project | Description | Status |

| 01 | Production Microservices Platform | Deploy frontend, backend and API services on Kubernetes. | In Progress |
| 02 | Enterprise Networking | Ingress, TLS, DNS, NetworkPolicies and service communication. | Planned |
| 03 | GitOps Platform | Implement GitOps deployments using Argo CD and Helm. | Planned |
| 04 | Monitoring & Observability | Set up Prometheus, Grafana, dashboards and alerts. | Planned |
